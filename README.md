# 安装步骤

```shell
git clone https://github.com/lejianwen/rustdesk-api-web
cd rustdesk-api-web   
npm install

// 本地开发
npm run dev

// 打包
npm run build

```

## Форк Armilen

Расхождение с апстримом сведено к одному скрипту правок, сами исходники не
трогаются. Тот же принцип, что у `apply-branding` в форке клиента RustDesk:
слияние с апстримом не конфликтует, потому что конфликтовать нечему.

```
python3 scripts/apply-armilen.py   # идемпотентно
npm run build
```

| Что | Где |
| --- | --- |
| Русский перевод: 61 ключ сверх апстрима и 3 переформулировки | `i18n/ru-armilen.json` |
| Заголовки и пояснения на 5 страницах серверных настроек | правятся скриптом в `src/views/rustdesk/` |
| Фавиконки | `branding/` |
| Заголовок вкладки | правится скриптом в `index.html` |
| Выбор темы: общая кука `theme` на `.armilen.ru` | бутстрап в `index.html`, правится скриптом |

Тема панели больше не живёт отдельно от сайта. Мнение о ней одно на все
поверхности проекта и лежит в куке `theme` на родительском домене (ADR 0030 в
репозитории сайта): `localStorage` изолирован по origin, поэтому выбор,
сделанный на www, до панели не доезжал. Панельный `useDark()` из `@vueuse/core`
про куку не знает и читает свой ключ `vueuse-color-scheme`, поэтому кука не
заменяет его, а ведёт: бутстрап читает куку, кладёт то же значение в ключ и
успевает это сделать до монтирования Vue. Обратная сторона: наблюдатель за
классом `dark` пишет куку при любом переключении, в том числе родным
`el-switch`, иначе выбор, сделанный в панели, остался бы только в ней.

Из 61 ключа сверх апстрима 14 закрывают настоящие пробелы его перевода (`Bind`, `Client`, `Token` и другие) и годятся для PR в апстрим, 10 обслуживают пары заголовок-пояснение на страницах настроек, остальные унаследованы от прежнего форка и ничем не отображаются: они сохранены как есть, чтобы ничего не потерять при восстановлении.

Апстрим показывает в заголовке карточки сырое имя опции (`ALWAYS_USE_RELAY`). Скрипт заменяет его переведённым названием и добавляет абзац с объяснением, что опция делает, на всех пяти страницах.

Переформулировки намеренные: `PeerManage` «Пиры» → «Все партнёры»,
`AddressBookName` → «Раздел адресной книги», `AddressBookNameManage` →
«Категории». В апстрим они не отдаются, в отличие от 61 недостающего ключа.

Перевод восстановлен из собранного бандла на боевом сервере: исходники
прежнего форка были потеряны, а карта ключей i18n пережила минификацию.
Инструмент восстановления и исходные бандлы лежат в `rustdesk-admin-recovery`.

Сборку и публикацию артефакта делает `.github/workflows/build-admin.yml`:
подтягивает апстрим, накладывает правки, проверяет что они применились,
собирает и кладёт `armilen-admin-dist.tgz` в релиз. VPS скачивает этот ассет
тем же способом, каким уже качает релизы `rustdesk-api`.
